# MotoApp

Трекер мотопоїздок. PWA — ставиться на iPhone через Safari «Поділитися → На початковий екран», без App Store і без $99.

## Що вже вміє

- Записує маршрут по GPS і малює його на темній карті в реальному часі
- Тримає екран увімкненим під час поїздки (Wake Lock)
- Рахує дистанцію, час загальний і час у русі, поточну/середню/максимальну швидкість, набір висоти
- Пауза / продовження без розриву треку прямою лінією
- Історія поїздок з назвою і нотатками, все зберігається в памʼяті телефона (працює офлайн)
- Навігація: пошук місця за назвою або довге натискання на карті, маршрут лінією, банер із наступним маневром, голосові підказки українською в гарнітуру, перебудова маршруту при звертанні не туди, обхід автомагістралей
- Виявлення падіння за акселерометром: 30 секунд на скасування, далі сигнал лиха групі з координатами, виклик 112 і готове SMS рідним
- Спільна поїздка: код групи вводиться один раз, далі райдери бачать одне одного на карті; голос попереджає, якщо хтось відстав. Позиції живуть 2 години і зникають самі
- Орієнтація карти за рухом або північчю вгору
- Погода вздовж маршруту на час прибуття в кожну точку (Open-Meteo, без ключів); дощ, туман і сильні пориви підсвічуються й попереджаються голосом
- Гараж: пробіг мотоцикла, який сам росте від записаних поїздок; пункти обслуговування з інтервалами в км і днях, підсвічування прострочених; журнал виконаних робіт з вартістю

## Запуск

```bash
npm run dev
```

Далі відкрити http://localhost:5173

### Перевірка без байка

Відкрий http://localhost:5173/?sim=1 — застосунок вдаватиме, що ти їдеш, і запише справжню поїздку в базу. Зручно, щоб дивитись на HUD і карту за столом.

Стартову точку симулятора можна задати: `?sim=1&lat=19.07&lng=72.87` — так перевіряють поведінку в іншій країні або в іншій погоді.

## Важливо про телефон

Геолокація і Wake Lock працюють **тільки через HTTPS** (або localhost). Тобто відкрити застосунок на айфоні за локальною IP-адресою на кшталт `http://192.168.0.5:5173` не вийде — Safari заблокує GPS. Для реального тесту на дорозі проєкт треба залити на безкоштовний хостинг (Vercel / Netlify), там HTTPS дається сам.

## Публікація на Vercel

Один раз:

1. Створити на GitHub порожній репозиторій `MotoApp` (можна приватний).
2. Підключити його і залити код:

```bash
git remote add origin https://github.com/ВАШ_ЛОГІН/MotoApp.git
git branch -M main
git push -u origin main
```

3. На vercel.com увійти через GitHub → Add New Project → вибрати `MotoApp` → Deploy. Налаштування чіпати не треба, Vercel сам розпізнає Vite.

Далі кожен `git push` публікується автоматично.

### Що має бути налаштовано на Vercel

- `ORS_API_KEY` — ключ OpenRouteService (Settings → Environments → Production → Environment Variables). Потрібен для маршрутів і пошуку місць.
- Сховище Upstash Redis (Storage → Create Database → Upstash → Redis, тариф Free, підключити до проєкту). Потрібне для спільної поїздки; змінні Vercel додає сам.

Погода працює без жодних ключів.

## Технології

- Vite + React + TypeScript
- MapLibre GL + OpenFreeMap (карта без ключів і оплати)
- Dexie (IndexedDB) — локальне сховище поїздок
- vite-plugin-pwa — офлайн і встановлення на початковий екран
