# MotoApp

Трекер мотопоїздок. PWA — ставиться на iPhone через Safari «Поділитися → На початковий екран», без App Store і без $99.

## Що вже вміє

- Записує маршрут по GPS і малює його на темній карті в реальному часі
- Тримає екран увімкненим під час поїздки (Wake Lock)
- Рахує дистанцію, час загальний і час у русі, поточну/середню/максимальну швидкість, набір висоти
- Пауза / продовження без розриву треку прямою лінією
- Історія поїздок з назвою і нотатками, все зберігається в памʼяті телефона (працює офлайн)

## Запуск

```bash
npm run dev
```

Далі відкрити http://localhost:5173

### Перевірка без байка

Відкрий http://localhost:5173/?sim=1 — застосунок вдаватиме, що ти їдеш, і запише справжню поїздку в базу. Зручно, щоб дивитись на HUD і карту за столом.

## Важливо про телефон

Геолокація і Wake Lock працюють **тільки через HTTPS** (або localhost). Тобто відкрити застосунок на айфоні за локальною IP-адресою на кшталт `http://192.168.0.5:5173` не вийде — Safari заблокує GPS. Для реального тесту на дорозі проєкт треба залити на безкоштовний хостинг (Vercel / Netlify), там HTTPS дається сам.

## Технології

- Vite + React + TypeScript
- MapLibre GL + OpenFreeMap (карта без ключів і оплати)
- Dexie (IndexedDB) — локальне сховище поїздок
- vite-plugin-pwa — офлайн і встановлення на початковий екран
